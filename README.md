# SKBM Katalog Fasilitator

UI/UX katalog fasilitator SKBM (Sekolah KIR Binaan KPM) dengan fokus pada keahlian, dampak, dan komunikasi via WhatsApp tanpa login.

## Fitur Utama
- Beranda dengan hero, statistik jejaring, kategori program, fasilitator unggulan, dan testimoni.
- Katalog fasilitator dengan filter dan kartu profil.
- Halaman profil fasil lengkap dengan form rencana + generator WhatsApp.
- Halaman pendukung: program, jejaring, prestasi, tentang, cara kerja, testimoni, FAQ, dan kontak.

## Menjalankan Project
```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.
